## 1. The estimator architecture (current)

**State (6):** `x = [ψ, φ, θ, b_x, b_y, b_z]` — attitude (ZXY Euler) + gyro bias.

**Form:** "gyro-as-input" (the standard attitude EKF). The gyro is **not** a measurement; it **drives** the prediction. The measurements are the **accelerometer** (gravity tilt → roll/pitch) and the **magnetometer** (heading → yaw).

**Cycle:**
```
PREDICT:  omega_hat = z_gyro − b_hat            % bias-corrected rate
          attitude propagated via ZXY kinematics(att, omega_hat)
          bias propagated as constant (random walk; growth via Q)
          F = [ A_att  −B_att ; 0  I ]          % see below
          P_pred = F P Fᵀ + Q
UPDATE 1 (accel):  z = [g·sinθ; −g·sinφ·cosθ; −g·cosφ·cosθ],  H_a = [H_att | 0₃]
UPDATE 2 (mag):    z = ψ,  H_m = [1 0 0 | 0 0 0]
```

**Jacobian block structure (the key reuse trick):**
- `A_att` (3×3) = `I + dt·∂kin/∂att` — the verified attitude block (incl. the fixed `F(3,3)=1+dt·(wx·cθ·tφ+wz·sθ·tφ)`).
- `B_att` (3×3) = `dt·∂kin/∂omega` — the rate-sensitivity block.
- **Bias block = `−B_att`** because `omega = z_gyro − b` ⇒ `∂att/∂b = −∂att/∂omega`.
- Bias rows = `[0₃ | I₃]` (random walk).

**Files (on branch):**
- `dynamics/ekf_att_bias.m` — the new filter (gyro-as-input, bias, accel + mag updates).
- `dynamics/ekf_attitude.m` — baseline 6-state `[att, rates]` (kept for comparison; F(3,3) fixed).
- `dynamics/imu_simulate.m` — gyro (+ const bias `[0.003,−0.002,0.001]` + noise σ=0.005), accel (gravity-tilt + noise σ=0.02), **magnetometer heading** (`z_mag = ψ + 1°·randn`). Returns `[z_gyro, z_accel, z_mag]`.
- `sim/test_ekf.m` — the validation harness.

**Current tuning:** `P0 = diag([0.1 0.1 0.1, 1e-4 1e-4 1e-4])`; `Q = blkdiag(1e-5·I₃, 1e-6·I₃)` (bias RW = 1e-6 is the sweet spot); `R_accel = (0.02)²·I`; `R_mag = (1°)²`.

## 2. The journey so far (what was done and learned)

1. **Built a real validation harness.** Truth is generated by **integrating the actual closed-loop flight** (`ode45` of `rigid_body` + `sas_cmd`) on a **fixed 100 Hz grid** (`tgrid = 0:dt:T`) from a **perturbed IC** (so the filter has motion to estimate). Diagnostics: **estimate-vs-truth**, **error-vs-±3σ**, **NEES**. *(The old `test_ekf.m` prescribed attitude & rates independently — physically inconsistent; this fixes that.)*

2. **Numerical Jacobian verification (`numjac`).** Central differences vs the analytic `F`, at a *rich* test point (nonzero rates AND angles). It caught a **two-part bug in `F(3,3)`**: a **missing identity term** (`F(3,3)=dt·(...)` overwrote the `eye(6)` diagonal `1`) **and** a **sign error** on the `wz` term. Corrected to `F(3,3)=1+dt·(wx·cθ·tφ+wz·sθ·tφ)`, verified to ~1e-9. *Lesson: eyes catch sign slips but miss missing terms; the mismatch magnitude (~1 vs ~1e-4) diagnoses which.*

3. **Step 2 — gyro-bias estimation (gyro-as-input restructure).** Swapped the 3 rate-states for 3 bias-states; gyro became an input. Result (validated in Octave + MATLAB): `bx → +0.003`, `by → −0.002` (observable via roll/pitch), `bz` stuck near 0. *Lesson: bias is observable only on observable-attitude axes; convergence speed is set by `Q_bias`; estimators learn from excitation (it slows once the aircraft settles to trim).*

4. **Step 3 — magnetometer heading update (just added).** One linear update `H = [1 0 0 | 0 0 0]` makes **yaw observable**, which in turn makes **`bz` observable** (it only couples to the world through yaw). Expected: yaw error bounds **plateau** (instead of widening), `bz` climbs to +0.001, NEES tightens toward 6.

### Consistency findings
- Full-run NEES dropped 7.18 → 6.91 after the Jacobian fix (small — the fix mostly affects covariance, and observable states are measurement-dominated).
- Steady-state NEES (t>1) was **4.96** *before* the magnetometer — decoded as: the **unobservable yaw contributed ~0** (huge variance, tiny error), dragging the aggregate below 6, while the **observable states were consistent** (≈5 on the 5-state observable subspace). *Lesson: aggregate NEES is contaminated by unobservable states; per-state error-vs-±3σ is the clean diagnostic. The magnetometer should restore yaw's contribution and pull NEES toward a clean 6.*

## 3. Current working code

### `dynamics/ekf_att_bias.m` (verified correct)
```matlab
function [x, P] = ekf_att_bias(x, P, z_gyro, z_accel, z_mag, dt, Q, R_accel)
    g = 9.81;
    phi = x(2); theta = x(3); b = x(4:6);
    % PREDICT (gyro as input)
    omega = z_gyro - b;  wx=omega(1); wy=omega(2); wz=omega(3);
    cth=cos(theta); sth=sin(theta); cph=cos(phi); tph=tan(phi); inv_cph=1/sqrt(cph^2+1e-6);
    dpsi=(-wx*sth+wz*cth)*inv_cph;  dphi=wx*cth+wz*sth;  dtheta=wy+wx*sth*tph-wz*cth*tph;
    x_pred = [x(1:3)+dt*[dpsi;dphi;dtheta]; b];
    F = eye(6);
    F(1,2)=dt*((-wx*sth+wz*cth)*sin(phi)*inv_cph^2);  F(1,3)=dt*((-wx*cth-wz*sth)*inv_cph);
    F(2,3)=dt*(-wx*sth+wz*cth);
    F(3,2)=dt*(wx*sth/cph^2-wz*cth/cph^2);  F(3,3)=1+dt*(wx*cth*tph+wz*sth*tph);
    B_att=[dt*(-sth*inv_cph),0,dt*(cth*inv_cph); dt*cth,0,dt*sth; dt*(sth*tph),dt,dt*(-cth*tph)];
    F(1:3,4:6)=-B_att;
    P_pred = F*P*F' + Q;
    % UPDATE 1: accelerometer
    phi2=x_pred(2); theta2=x_pred(3);
    z_pred_a=[g*sin(theta2); -g*sin(phi2)*cos(theta2); -g*cos(phi2)*cos(theta2)];
    H_a=zeros(3,6);
    H_a(2,2)=-g*cos(phi2)*cos(theta2); H_a(3,2)=g*sin(phi2)*cos(theta2);
    H_a(1,3)=g*cos(theta2); H_a(2,3)=g*sin(phi2)*sin(theta2); H_a(3,3)=g*cos(phi2)*sin(theta2);
    y_a=z_accel-z_pred_a; S_a=H_a*P_pred*H_a'+R_accel; K_a=P_pred*H_a'/S_a;
    x=x_pred+K_a*y_a; P=(eye(6)-K_a*H_a)*P_pred; P=(P+P')/2;
    % UPDATE 2: magnetometer (heading)
    H_m=zeros(1,6); H_m(1)=1; R_m=(deg2rad(1))^2;
    y_m=z_mag-x(1); S_m=H_m*P*H_m'+R_m; K_m=P*H_m'/S_m;
    x=x+K_m*y_m; P=(eye(6)-K_m*H_m)*P; P=(P+P')/2;
end
```

### `numjac` (Jacobian self-check)
```matlab
function J = numjac(fun, x, h)
    n=numel(x); J=zeros(n);
    for j=1:n, xp=x; xp(j)+=h; xm=x; xm(j)-=h; J(:,j)=(fun(xp)-fun(xm))/(2*h); end
end
```

## 4. Remaining roadmap

### ▶ Step 4 — Numerical robustness & tuning
- **Joseph-form covariance:** replace `P=(I−KH)P` with `P=(I−KH)P(I−KH)ᵀ + KRKᵀ` (guaranteed symmetric PSD; drop the `pinv`/`1e-9` patches in the baseline).
- **Tune `Q`/`R` by NEES/NIS**, not by eye. Target steady-state NEES ≈ 6 inside the χ² band.
- Optional: **coarse alignment** (seed φ,θ from the first accel sample) to kill the init NEES spike (~318→~6).
- Optional IMU fidelity: bias random-walk in truth, scale factor, misalignment, kinematic-acceleration term in the accel model.
